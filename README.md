E-Commerce Website – Django Project
An online shopping website built using Django where users can browse products, create accounts, log in, and explore categorized items.
The project is deployed on PythonAnywhere.

Live Demo:
https://muhammaduzair.pythonanywhere.com/

Features
* User Authentication (Signup/Login/Logout)
* Product Listing Page
* Category-wise Product Display
* Product Details & Descriptions
* Product Images Support
* Responsive Design using Bootstrap
* Admin Panel for Product Management
* Django Authentication System
* Dynamic Product Rendering from Database
* Deployment on PythonAnywhere

Technologies Used
* Backend: Python, Django
* Frontend: HTML, CSS, Bootstrap, JS
* Database: SQLite
* Deployment: PythonAnywhere

How to Install locally

1. Clone the Repository
2. Create Virtual Environment
3. Activate Virtual Environment
4. Install Dependencies
5. Run Migrations
6. Start Server
7. For Admin Panel create superuser
